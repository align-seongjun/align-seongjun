코드 저장소는 private, 문서와 릴리즈는 public입니다. 위 표의 링크는 소스가 아니라 문서·배포 저장소를 가리킵니다.

- **문서** — 요구사항·아키텍처·ADR을 프로젝트별 위키에 두고, 구현이 스펙과 갈라지면 문서를 먼저 갱신합니다.
- **진행 관리** — Issues와 Projects 보드가 단일 소스이며, 문서에는 Phase 단위 요약만 남깁니다.
